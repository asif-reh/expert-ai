# Expert AI

**AI that turns ordinary workers into experts.**

Inspired by Y Combinator's Winter 2027 Request for Startups: **The $15-an-Hour Expert**.

> AI that turns ordinary workers into experts for jobs like benefits, taxes, insurance, medical billing, and immigration.

## What it does

- Domain-specific expert copilots (starting with Immigration & Visas)
- Clear checklists, document requirements, timelines, and next steps
- Built for frontline workers and individuals navigating complex paperwork

## Quick start

1. Clone the repo
2. `npm install`
3. Add your OpenAI API key as `OPENAI_API_KEY` in `.env.local` or Vercel environment variables
4. `npm run dev`

## Deploy

Deployed on Vercel. Add `OPENAI_API_KEY` in Project Settings → Environment Variables.
